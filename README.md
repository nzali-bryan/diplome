Description du projet : Diplômes des enfants de chœur

Ce projet permet de générer automatiquement des diplômes pour les enfants de chœur.
Pour chaque enfant, on peut ajouter son nom, sa mention et la date, et le diplôme est créé directement à partir d’un modèle graphique.

Les diplômes sont ensuite sauvegardés dans la base de données, ce qui permet de les retrouver facilement plus tard.
